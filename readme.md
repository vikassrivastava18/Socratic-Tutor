## Key features
- RAG based document answering functionality using FAISS and LangChain.
- Socratic dialogue style tutor for learning concepts using LangGraph.
- Practice coding assignments with instant feedback


## Configuration
Add your OpenAI key using .env.example (backend/tutor/tutor)

## Quick Start

Run the application with
```
docker-compose build
docker-compose up
```
